# sita-technical-test
Technical test assestment
  
## Solution Overview

This repository contains solutions for the OptiFlight Coordinator technical test, organized as follows:

1. **Architecture Design**: See `architecture/sita.drawio` for the high-level Kubernetes architecture diagram.
2. **Python Job Processor Service**: Core logic, REST API, and tests are in the `job_processor` folder. See its `README.md` for details.
3. **Helm Implementation**: Helm chart and deployment artifacts are in the `helm` folder. Refer to its `README.md` for usage and configuration.

Each part is documented in its respective README for setup and usage instructions.
